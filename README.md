🪔 Diwali Sales Analysis – Python Data Analytics Project
📌 Project Overview

This project analyzes Diwali sales data to understand customer purchasing behavior, product performance, and revenue trends during the festive season.
The goal is to derive actionable business insights that can help improve marketing strategies, inventory planning, and customer targeting.

This project demonstrates an end-to-end data analytics workflow using Python, from raw data cleaning to insight generation.

🎯 Objectives

Analyze customer demographics and spending patterns

Identify top-performing products and categories

Understand gender-wise and age-wise purchasing behavior

Discover high-revenue states and occupations

Provide business recommendations based on insights

🗂️ Dataset Information

Source: Diwali Sales Dataset

Format: CSV

Records: Customer-level sales transactions

Key Features:

Customer demographics (Gender, Age Group, Marital Status)

Location details (State, Zone)

Product details (Category, Product ID)

Purchase amount

Occupation

🧰 Tools & Technologies

Python

Libraries: pandas, numpy, matplotlib, seaborn

Jupyter Notebook

Git & GitHub

🔍 Data Cleaning & Preparation

The following steps were performed:

Removed unnecessary columns

Handled missing values

Converted data types for analysis

Standardized column names

Filtered invalid or zero-value purchases

📊 Exploratory Data Analysis (EDA)

Key analyses performed:

Gender-wise sales and purchase behavior

Age group vs total purchase amount

State-wise sales contribution

Occupation-wise and product category-wise analysis

Identification of high-value customer segments

📈 Key Insights

Female customers contributed higher overall revenue

Customers aged 26–35 were the highest spenders

Certain states dominated festive sales revenue

IT, Healthcare, and Aviation professionals showed higher spending

Specific product categories performed exceptionally well during Diwali

💡 Business Recommendations

Focus marketing campaigns on high-spending age groups

Target high-performing states with region-specific offers

Promote top-selling product categories during festive seasons

Design personalized offers for repeat and high-value customers
